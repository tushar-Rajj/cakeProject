# 🎂 Cake World – E-Commerce Store

A full dynamic e-commerce platform for online cake shopping with **user & admin panels**, built using **Django, Python, HTML, CSS, JavaScript, and Bootstrap**.

---

## 🚀 Features
- User authentication (login/register).
- Browse, search, and filter cakes.
- Cart & checkout with payment integration.
- Order history & reviews.
- Admin panel for products & orders.
- Dashboard with analytics.
- Responsive UI (mobile-friendly).

---

## 🖥️ Tech Stack
- Backend: Django, Python  
- Database: SQLite  
- Frontend: HTML, CSS, JavaScript, Bootstrap  

---

## ⚡ Installation & Setup

# Clone repository
git clone https://github.com/your-username/cake-world.git
cd cake-world

# Create virtual environment
python -m venv env
source env/bin/activate   # On Windows: env\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Apply migrations
python manage.py migrate

# Run server
python manage.py runserver
